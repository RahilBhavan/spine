# Spine task router

Read only the references needed for the task, after `AGENTS.md` and `CONTRIBUTING.md`.

- Understanding or onboarding: `CODEBASE_GUIDE.md`, then `.t3/references/architecture.md`.
- Fetcher, API, or generated-data work: `.t3/references/architecture.md`, `.t3/references/commands.md`, `.t3/references/constraints.md`.
- Backtest, calibration, or risk-model work: `PLAN.md` section 4, `WRITEUP.md` sections 2-7, `.t3/references/architecture.md`, `.t3/references/verification.md`.
- Dashboard or rendered-writeup work: `.t3/references/architecture.md`, `site/index.html`, `site/app.js`, `spine/render_writeup.py`.
- CI, refresh, or publication work: `.github/workflows/`, `.t3/references/commands.md`, `.t3/references/constraints.md`.
- Scope and sequencing decisions: `ROADMAP.md`.

Canonical stable references:

- `.t3/PROJECT.md`: identity and boundaries.
- `.t3/references/architecture.md`: components, entry points, and data flow.
- `.t3/references/commands.md`: evidence-backed commands.
- `.t3/references/verification.md`: checks by change type.
- `.t3/references/constraints.md`: safety, compatibility, and non-goals.
