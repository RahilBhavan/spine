# Contributing

Rules the code follows. Reviews cite this file.

## Code
- Python 3.12. Standard library only, except `spine/backtest.py` (numpy, in `.venv`). No frameworks, no ORMs, no CLI libraries.
- No classes. Short functions, plain dicts and lists, module-level constants. Shared helpers live in `spine/api.py`; do not re-implement `load`, `save`, `day_ts`, `budget`, HTTP, or the market table locally.
- Parse `sys.argv` by hand and only under `if __name__ == '__main__':`. Importing a module must not read argv or touch the network.
- Every script ends with a `__main__` block that does its job and then asserts one or two things that would fail if the logic broke. No test frameworks inside scripts; `tests/` holds the reference checks.
- Any script that can run longer than four minutes takes `--max-seconds N` (default 200), checkpoints to `data/cache/`, prints `partial, rerun to continue` and exits 0 on the budget, and prints `complete` when done. Reruns are incremental.
- Comments only where the code is not obvious. A deliberate simplification with a known ceiling gets a `# ponytail:` comment naming the ceiling and the upgrade path.
- Numbers in `WRITEUP.md` come from `spine/writeup_tables.py` output, never typed in.

## Data
- Everything under `data/` is regenerated by a script in `spine/`; never hand-edit. `data/cache/` is ignored by git.
- Raw on-chain integers stay as strings in JSON (they exceed 2^53).
- Public endpoints only, no keys: Morpho GraphQL (750 req/min, `first` ≤ 1000, `skip` ≤ 10000), `https://mainnet.base.org` (2,000-block `eth_getLogs`, 429s under bursts: pace 0.25 s), Coinbase Exchange (10 req/s). Binance REST is geo-blocked from US IPs.

## Site
- Static files in `site/`, served from the repo root; no build step. Plotly from jsdelivr is the only external script. Colors as CSS variables on `:root` with a dark variant; phone width works.
- The page reads `data/summary.json` and other `data/*.json`; it never loads the 39k-row position files.

## Process
- One phase per pull request, named after the ROADMAP.md phase. Each phase has an acceptance check in PLAN.md or ROADMAP.md; paste its output in the PR.
- Level checks (market-dependent numbers) run only under `--check`; paste that output in the PR. The cron runs without it.
- Reviews run on two axes (standards: this file; spec: PLAN.md and ROADMAP.md) and are reported separately.
